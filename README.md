## 关于本记录

**本文是 AI 辅助整理成文的，不是人工手写。**

分工是这样：AI 负责抓取、比对、组织、成文；人负责选题、取材范围、判断、删改与发布。
所有事实性内容都指向可点开的原始文件——接口快照、提交 diff、截图、账单——
不需要相信作者，也不需要相信 AI，点开核对即可。

之所以把这件事写在最显眼的位置，有两个原因：

1. **AI 会编。** 这是它最稳定的缺陷。因此本文强制每一条事实都能回溯到仓库里的原始文件，
   回溯不到的宁可写「待核准」。这不是谦虚，是流程。
2. **来源清楚，判断才归读者。** 如果你认为 AI 整理的东西不足以作为依据，
   这个判断应该在你看到第一行时就能做出，而不是在你引用之后才发现。

本记录按事件整理归档，不是长期日志。

**写不出来的东西就不写**——能被别人独立验证的，才放进正文。
